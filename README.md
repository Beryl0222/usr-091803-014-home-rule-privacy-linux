# 家庭智能规则与隐私

本项目服务于家庭设备**本地编排**。三代同堂陆续添置门锁、摄像头、空调与睡眠设备后，
系统要在本地解决四件事：成员授权、设备能力、规则冲突与离线降级，并保证摄像/健康
数据的目的限定与执行记录的最小可见。

运行 `python3 service.py --check` 可检查基础配置；执行 `python3 service.py --port 8000`
后访问 `/health` 可以确认服务身份。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `home/models.py` | 领域对象：成员/角色、设备能力、同意、时间窗口、规则、访客凭证、事件、设备态 |
| `home/store.py` | 本地 JSON 持久化，临时文件原子替换；断网仍是唯一事实来源 |
| `home/privacy.py` | 同意与隐私门：敏感数据按"类别+目的"授权，撤回即时停止新使用 |
| `home/rules.py` | 规则管理：每次创建/修改/启停/删除都追加一条不可变版本 |
| `home/arbitration.py` | 冲突仲裁：安全级别 → 授权范围 → 时间，给出唯一且可解释的决定 |
| `home/resilience.py` | 降级恢复：离线/固件升级/缺传感器的保守兜底与恢复重放 |
| `home/audit.py` | 审计与可见性：按成员授权返回完整或脱敏视图 |
| `home/orchestrator.py` | 编排入口：去重 → 候选收集 → 隐私门 → 仲裁 → 降级执行 → 审计 |

## 一次事件的处理流水线

```
事件去重 → 收集候选(常驻规则/事件规则/访客凭证/手动指令) → 同意与隐私门
       → 冲突仲裁(每设备唯一决定) → 降级判断/执行 → 写审计(带可见名单)
```

* **冲突仲裁**逐级比较，结果可复现：`safety_level` 高者胜 → 同级比授权范围
  （安全兜底 > 管理员 > 授权成员 > 访客凭证）→ 再相同比时间（最新意图优先）→
  最后用稳定键兜底。每个落败动作都记录"在哪一级被谁压过"。
* 触发类型为 `*` 的规则是**常驻策略**（如夜间自动上锁），在其时间窗口内会与
  同一时刻的访客/手动意图在同一次仲裁中正面竞争——因此"夜间访客到来"只会产生
  一个决定。

## 需求落实对照

| 需求 | 实现 |
| --- | --- |
| 本地保存设备能力/同意/自动化条件/访客有效期 | `LocalStore` 原子写本地文件，`recover_device`/重启后从本地重建 |
| 断网时门锁不被云端规则剥夺控制 | 全部判定只依赖本地状态，无任何网络调用 |
| 多动作竞争给唯一可解释决定 | `Arbitrator` 三级排序 + `Decision.explain()` |
| 固件升级/缺传感器/设备离线降级与恢复 | `ResiliencePolicy` 兜底 + 挂起队列，`recover_device()` 重放重判 |
| 重复事件不再开锁/断电 | `processed_events` 幂等台账 + 设备级执行键，恢复重放也不重复 |
| 摄像/健康信息仅为获准用途读取 | `ConsentGate.authorize_read`（类别×目的×每位数据主体） |
| 撤回同意后停止新使用 | `withdraw` 即时生效；保护性的"停止查看"动作不依赖同意 |
| 每次规则修改留版本 | `rule_versions` 只追加的不可变快照 |
| 只查自己有权知道的结果 | `AuditService.query/explain` 按完整/脱敏名单过滤 |
| 能确认动因为何发生 | 完整视图含触发事件、规则、行为人及仲裁理由 |
| 不能由记录推断他人敏感活动 | 他人摄像/健康仅返回设备级脱敏：隐去人员、房间、参数与可见名单；无权记录与"不存在"不可区分 |

## 降级策略（保守优先安全与隐私）

* 门锁在信息不足或升级中**保持闭锁**，绝不自动开锁；
* 老人夜间照明缺少人体感应时**保持点亮**以防跌倒；
* 不依据不完整读数**切断空调电源**；
* 无法确认授权语境时**不推送摄像画面**；
* 设备离线时动作挂起，恢复在线后重放当时事件并重新仲裁，已执行过的动作不重复。

## 测试

```bash
npm test          # 3 个服务契约 + 54 个领域测试
python3 -m unittest discover -s tests
```

端到端场景见 `tests/fixtures.py` 与 `tests/test_orchestration.py`：老人夜间照明与
父母省电关灯竞争、父母夜间摄像限制、夜间访客与常驻上锁策略同时冲突、访客凭证
过期/撤销、断网重启、同意撤回、降级恢复与幂等。
